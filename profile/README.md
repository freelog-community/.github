# FreeLog

FreeLog 是一个**支持主题与插件（微前端架构）的数字资源发行与托管平台**。我们相信数字内容的分发应该开放、可组合、可自动化，因此将平台核心与配套工具全部开源。

## 平台做什么

FreeLog 同时服务两类用户：**资源创作者**和**开发者**。

**对资源创作者（无需写代码）：**
- 上传小说、漫画、图片、音频、视频等数字内容，自主定价、自主设置授权策略
- 选择现成的主题与插件来呈现内容，无需前端开发即可搭建自己的数字资源站点
- 借助平台完成资源的发行、推广与托管

**对开发者：**
- **主题**：完整的前端项目，决定站点外观与布局，例如小说主题、播客主题、漫画主题
- **插件**：被主题调用的小型组件，如音乐播放器、阅读器，通过运行时 API 挂载到页面中

资源创作者提供内容，开发者提供主题与插件，两者在 FreeLog 运行时环境中组合，形成完整的数字资源站点。

## 用 CLI 让 Agent 帮你发布

FreeLog 提供官方 CLI 工具 `@freelog-cli/cli`，覆盖资源从创建到上架的全流程：
[CLI 的使用文档地址](https://widget-docs.freelog.cn)
CLI 的命令行特性天然适合被脚本或 AI Agent 调用。你可以在 Agent 工作流中集成 FreeLog CLI，让 Agent 自动完成构建、版本管理与发布上架，减少人工操作。
