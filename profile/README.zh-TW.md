# FreeLog

FreeLog 是一個**支援主題與外掛（微前端架構）的數位資源發行與託管平台**。我們相信數位內容的發行應該開放、可組合、可自動化，因此將平台核心與配套工具全部開源。

## 平台做什麼

FreeLog 同時服務兩類使用者：**資源創作者**和**開發者**。

**對資源創作者（無需寫程式）：**
- 上傳小說、漫畫、圖片、音訊、影片等數位內容，自主定價、自主設定授權策略
- 選擇現成的主題與外掛來呈現內容，無需前端開發即可打造自己的數位資源網站
- 藉助平台完成資源的發行、推廣與託管

**對開發者：**
- **主題**：完整的前端專案，決定網站外觀與版面配置，例如小說主題、播客主題、漫畫主題
- **外掛**：被主題呼叫的小型元件，如音樂播放器、閱讀器，透過執行時 API 掛載到頁面中

資源創作者提供內容，開發者提供主題與外掛，兩者在 FreeLog 執行時環境中組合，形成完整的數位資源網站。

## 用 CLI 讓 Agent 幫你發佈

FreeLog 提供官方 CLI 工具 `@freelog-cli/cli`，涵蓋資源從建立到上架的完整流程：
[CLI 的使用文件位址](https://widget-docs.freelog.cn)

CLI 的命令列特性天然適合被指令碼或 AI Agent 呼叫。你可以在 Agent 工作流程中整合 FreeLog CLI，讓 Agent 自動完成建置、版本管理與發佈上架，減少人工操作。
